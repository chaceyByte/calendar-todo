# 任务日历项目 (Task Calendar)

一个功能丰富的任务管理和日历应用，支持拖拽任务、日历视图、标签管理和AI功能。

## 项目结构

```
calendar-todo/
├── frontend/          # Vue3前端项目
├── backend/           # Spring Boot后端项目
└── README.md         # 项目说明
```

## 技术栈

### 前端
- Vue 3 + Composition API + TypeScript
- Vue Router + Pinia
- Element Plus UI组件库
- ECharts图表库
- VueUse工具库

### 后端
- Spring Boot 3.x
- Spring Boot AI
- MyBatis Plus
- MySQL/PostgreSQL
- Spring Security

## 功能特性

### 首页
- 人员信息栏
- 标签页切换动画
- 任务统计图表
- 甘特图展示

### 日历模块
- 月视图展示任务
- 右键导出日报/周报
- 月份翻页

### 任务看板
- 三栏式布局（计划中/制作中/已完成）
- 拖拽功能
- 快捷键支持（Alt+Enter）
- 暂存队列

### 标签管理
- 标签CRUD操作
- 与任务联动

### AI功能
- 日报润色
- 周报智能生成
- 任务处理建议
